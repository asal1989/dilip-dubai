# Trio Built Gulf — Essential (₹12,000)

A single static one-page site. No build step, no server.

```
essential/
  index.html      all markup + styles (inline) + a small vanilla script
  assets/         logo variants + favicon
```

## What's included (per quotation)

- Full one-page site — Hero, About, Services (11), Why Us, Team, Projects, Contact
- Click-to-call, WhatsApp and email links
- Quote-request form that opens a pre-filled **email draft** to `triobuiltgulf@gmail.com`
- Brand system — navy / teal / cream palette, Fraunces + Inter + IBM Plex Mono, peak-divider motif
- Optimised images (sized PNGs, `width`/`height` set, `loading` hints) and a single inline stylesheet for fast first paint
- Search-engine tags — `<title>`, meta description, Open Graph

## Not in this tier

`robots.txt` / `sitemap.xml`, JSON-LD structured data, a formal accessibility pass,
cross-device QA, or a server-connected form — those are Professional / Premium.

## Deploy

Upload the whole `essential/` folder to any static host (Netlify, Cloudflare Pages,
GitHub Pages, cPanel). Set the project photos by replacing the `.proj` placeholders
in `index.html`.
